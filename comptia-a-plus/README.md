# CompTIA A+ Certification

Comprehensive study materials for CompTIA A+ certification preparation (1001/1002 exams).

## Overview

This section contains organized study materials, notes, and practice resources for passing the CompTIA A+ certification exams. The CompTIA A+ is a foundational certification for IT professionals covering hardware, networking, mobile devices, and troubleshooting.

- [Practice Quizzes](./practice-quizzes/) - Exam preparation questions

## Learning Objectives

### Hardware
- [ ] Identify motherboard components
- [ ] Understand RAM types and speeds
- [ ] Know storage device types
- [ ] Recognize expansion cards
- [ ] Troubleshoot hardware issues

### Networking
- [ ] Understand TCP/IP model
- [ ] Know common protocols
- [ ] Identify network topologies
- [ ] Configure network connections
- [ ] Troubleshoot network issues

### Troubleshooting
- [ ] Follow systematic troubleshooting methodology
- [ ] Identify common problems
- [ ] Apply appropriate solutions
- [ ] Document troubleshooting steps
- [ ] Prevent future issues

## Exam Information

### CompTIA A+ 1001
- **Duration**: 90 minutes
- **Questions**: 90 questions
- **Passing Score**: 675/900 (75%)
- **Domains**:
  1. Mobile Devices (14%)
  2. Networking (20%)
  3. Hardware (27%)
  4. Virtualization & Cloud Computing (12%)
  5. Hardware & Network Troubleshooting (27%)

### CompTIA A+ 1002
- **Duration**: 90 minutes
- **Questions**: 90 questions
- **Passing Score**: 675/900 (75%)
- **Domains**:
  1. Operating Systems (31%)
  2. Security (22%)
  3. Software Troubleshooting (24%)
  4. Operational Procedures (23%)
