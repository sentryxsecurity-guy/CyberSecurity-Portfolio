# Screenshots

Application and system screenshots demonstrating concepts and configurations.

## Organization

Screenshots are organized by section:

```
screenshots/
├── comptia-a-plus/
├── linux/
├── python/
├── networking/
├── labs/
└── general/
```

## Naming Convention

`[section]-[topic]-[description].png`

**Examples**:
- `comptia-a-plus-motherboard-atx-form-factor.png`
- `linux-terminal-ls-output-detailed.png`
- `networking-wireshark-tcp-handshake.png`
- `labs-kali-linux-desktop-environment.png`

## Quality Standards

- **Format**: PNG (preferred) or JPG
- **Resolution**: 1920x1080 or higher
- **File Size**: 2-5 MB max (after compression)
- **Quality**: Clear and readable

## Usage in Documentation

Reference screenshots in relevant documentation files:

```markdown
## Example Output

![Screenshot of terminal output showing file listing](../../assets/screenshots/linux-terminal-ls-output-detailed.png)

The above screenshot demonstrates the detailed output of the `ls -la` command.
```

## Sanitization Checklist

Before adding screenshots:

- [ ] No real IP addresses (use 192.168.x.x)
- [ ] No real hostnames
- [ ] No credentials visible
- [ ] No personal information
- [ ] No sensitive data
- [ ] Use placeholders where needed
- [ ] Add redaction notes if applicable
