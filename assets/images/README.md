# Images

General images and visual resources used throughout the portfolio.

## Organization

```
images/
├── icons/          # Small icon graphics
├── banners/        # Header/banner images
├── logos/          # Logo graphics
└── general/        # Other general images
```

## Naming Convention

`[type]-[purpose].png`

**Examples**:
- `icon-security.png`
- `banner-comptia-certification.png`
- `logo-linux.png`
- `badge-completed.png`

## File Formats

- **PNG**: Preferred (transparency, lossless)
- **SVG**: For scalable graphics
- **JPG**: For photographs only

## Size Guidelines

### Icons
- 16x16, 32x32, or 64x64 pixels
- File size: < 50 KB

### Banners
- 1200x300 or 1920x400 pixels
- File size: < 500 KB

### General Images
- Appropriate for content
- File size: < 2 MB

## Usage

Link in markdown:

```markdown
![Icon description](../../assets/images/icon-name.png)
```
