### Virtual Lab Setup

1. Install VirtualBox or VMware
2. Create Ubuntu 20.04 LTS VM
3. Allocate minimum 2GB RAM
4. Install common tools
5. Create snapshots for practice

```bash

# Start with basic navigation
ls                  # List files
pwd                 # Print working directory
cd ~                # Go to home
```

## Common Commands Cheatsheet

### File Operations
```bash
ls        # List directory contents
cd        # Change directory
mkdir     # Create directory
rm        # Remove files
cp        # Copy files
mv        # Move/rename files
find      # Search files
```

### Text Processing
```bash
cat       # Display file contents
grep      # Search text
sed       # Stream editor
awk       # Text processing
cut       # Extract columns
sort      # Sort lines
```

### System Information
```bash
uname     # System information
df        # Disk usage
du        # Directory size
top       # Process monitor
ps        # List processes
whoami    # Current user
```
